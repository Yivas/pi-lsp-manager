`pi-lsp-manager` resolves and reuses language servers for Pi. Version `0.2.0` provides diagnostics, navigation, symbols, guarded rename, and guarded source-action application without replacing the repository's formatter, linter, type checker, tests, or CI.

:::caution[Language servers are trusted local programs]
Language servers run with Pi's operating-system permissions. Trust a project only after reviewing it. The extension limits when a server is installed, started, or allowed to write; it does not sandbox the server.
:::

## Current support boundary

The built-in TypeScript route is the only route that can be installed automatically and the only route with platform-tested compatibility rows. Other catalog entries are candidates: review and configure them as global manual routes before use. A listed or detected executable is not a support claim.

Read the [verified compatibility rows](/pi-lsp-manager/operations/compatibility/) before relying on a platform or server combination.
